Живой MiniDV на macOS 26 (Apple Silicon)

Sony DCR-PC115E по FireWire/i.LINK: побитовая оцифровка лент и камера со звуком в реальном времени — в OBS, Chrome, Zoom. На машине, из которой Apple удалила весь стек FireWire.

Что здесь есть.
  • Полный гайд — стек, установка драйвера, найденные баги, методика оцифровки, живой режим: звук, геометрия кадра, ярлык, браузер.
  • Настройка живого режима — флаги, диагностика без камеры, ограничения.
  • Типичные проблемы — симптом → что проверить.
  • Звук: шум и эхо — микрофон, комната, фильтры OBS и обработка FFmpeg.
  • Репозиторий — README (RU/EN), инструменты, патч к ASFireWire.
Звук
Берётся прямо из DV-потока, без отдельного аудиокабеля: 16 бит/48 кГц и 12 бит/32 кГц, оба режима сверены с FFmpeg побитово. Приёмник — BlackHole, приложения видят звук с камеры как микрофон.
Геометрия
16:9WIDE у Sony пишется анаморфно: без растяжки картинка выходит сжатой по ширине на 42 %. Правильно: 4:3 → 768×576, 16:9 → 1024×576. Проверка — --dv-frame-selftest.
Быстрые команды.
  • --list-audio-devices, --audio-selftest 3 — звук без камеры;
  • --dv-audio-selftest test48.dv --pcm-out out.pcm — прогон .dv через боевой путь;
  • --dv-frame-selftest wide.dv --png wide.png — режим кадра и растяжка;
  • MINIDV_NO_DIALOG=1 "/Applications/MiniDV Live.app/Contents/MacOS/MiniDVLive" — живой режим без окон.
